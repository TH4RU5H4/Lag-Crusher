# Stand Power Pinger

App Concept & Overview Create a mobile application UI and code design for a mobile internet stabilization pinger app inspired by "Z Pinger." The visual theme must heavily incorporate JoJo’s Bizarre Adventure aesthetic—featuring dramatic, bold typography, stylized halftone dot patterns, high-contrast black-and-white ink lines with vibrant accent colors (vivid magenta, neon cyan, or electric gold), and dynamic, exaggerated action-line animations on every single interactive element.

Core UI Components & Controls

Service Provider & URL Selector: A prominent dropdown menu allowing users to switch between predefined Sri Lankan mobile network providers (Dialog, Mobitel, Hutch, Airtel) which automatically populates optimized ping URLs. Include an option or adjacent input field for "Custom URL" so users can input and save any arbitrary web address.

Interval Delay Selector: A second dropdown menu to select the ping delay/interval frequency (e.g., 1 second, 3 seconds, 5 seconds, 10 seconds).

Control Center: A central, oversized JoJo-style action button (labeled "START PING" / "STAND POWER") that initiates the connection stabilization loop, complete with a live status indicator.

Animation & Styling Requirements (JoJo Style)

Interactive Feedback: Every single click, tap, or dropdown selection must trigger an immediate, exaggerated animation. Use burst effects, dramatic screen shakes, floating Japanese sound effect typography (e.g., ゴゴゴゴ / Menacing or ドドドド /ドドド style rumble characters) popping up on screen, and sudden scale-zooms.

Transitions: Smooth yet punchy slide-ins and panel expansions resembling manga panel flips or dramatic character entrances.

Color Palette: Deep shadows, stark ink-wash gradients, and glowing neon highlights to evoke a high-energy anime visual style.
